# SBI反馈模型

在团队协作和个人成长中，**反馈**是不可或缺的燃料。然而，不恰当的反馈方式，往往会事与愿违。过于模糊的反馈（如“你做得不错”）无法提供具体的指导，而过于主观或带有评判性的反馈（如“你这个人太粗心了”）则容易引发对方的抵触和防卫心理，让一场本应有建设性的对话，变成一场无效的争论。**SBI反馈模型（Situation-Behavior-Impact Model）** 正是为解决这一难题而设计的一种简单、清晰、非评判性的**结构化反馈沟通工具**。

SBI模型由全球知名的领导力发展机构——**创新领导力中心（Center for Creative Leadership, CCL）**开发，其核心在于，通过将一次反馈，清晰地分解为三个逻辑连续的部分，来确保你的反馈是**具体的、客观的、并聚焦于行为及其产生的影响**，而非对个人性格的抽象评判。

*   **S - 情境（Situation）**：反馈所针对的具体时间和地点。
*   **B - 行为（Behavior）**：在该情境下，对方所表现出的、可被观察到的具体言行。
*   **I - 影响（Impact）**：该行为对你、对团队或对项目所产生的具体影响和后果。

通过遵循这个“S-B-I”的结构，你可以将反馈从“对人”的模糊评判，转变为“对事”的清晰描述，从而极大地提高反馈被对方理解和接受的可能性，并为后续的讨论和改进，奠定一个客观、尊重的基础。

!!! abstract "要点速览"

    - **一句话公式**：“在（什么时候、什么场合），你（做了/说了什么），这让（我/团队/项目）（产生了什么影响）。”
    - **行为要可观察**：写下摄像机能拍到的东西，而不是你对对方动机和性格的推测。
    - **影响要真实具体**：说清对你、对团队或对结果的实际影响，用“我”开头。
    - **说完要停下来听**：SBI 是对话的开始，不是一次单方面的宣判。CCL 的扩展版 SBII 正是在最后加上了“询问意图”。
    - **正面反馈同样适用**：具体的表扬比“你真棒”更能让好行为持续下去。

## SBI模型的三个构成部分

SBI的三个部分，共同构成了一个完整的、有说服力的反馈陈述。

1.  **S - 情境（Situation）**

    *   **目的**：为反馈提供一个清晰的上下文，帮助对方快速地回忆起你所指的具体是哪一件事。这避免了泛泛而谈和“翻旧账”。
    *   **关键**：要具体，不要模糊。不说“你总是…”，而要说“在昨天上午的项目周会上…”。

2.  **B - 行为（Behavior）**

    *   **目的**：将反馈的焦点，牢牢地锁定在对方**具体、客观、可被观察到**的言行上。
    *   **关键**：只描述你亲眼看到或听到的事实，**避免使用任何带有主观臆断、动机揣测或性格评判的词语**。不说“你当时显得很没准备”，而要说“你在介绍方案时，有三次中断并回头去翻找数据”。不说“你打断我”，而要说“在我刚才发言的中间，你开始说话了”。

3.  **I - 影响（Impact）**

    *   **目的**：这是反馈的核心。它旨在帮助对方理解，为什么他的这个行为是重要的，以及它对他人或工作造成了什么样的具体后果。这是激发对方产生改变意愿的关键。
    *   **关键**：清晰地阐述这个行为对“**我**”或“**我们**”所产生的真实影响或感受。使用“我”字句（I-Statement）开头，可以有效地降低对方的防卫心理。例如，“这让我感到我的观点没有被充分尊重”，或者“这让我们的客户对我们的专业性产生了疑问”。

### 把评判改写成行为描述

“行为”这一步最容易写偏。一个简单的检验方法：**如果用摄像机把当时的场景录下来，你说的内容能在录像里看到吗？** 看不到的，就是评判或推测。

| 评判或推测（避免） | 可观察的行为（推荐） |
| --- | --- |
| 你态度不好 | 客户提问时，你两次说“这个不归我管” |
| 你不重视这个项目 | 这周的三次站会，你都晚到了十分钟以上 |
| 你太粗心了 | 报告第 3 页和第 7 页的销售数字不一致 |
| 你表现得很专业 | 客户质疑价格时，你拿出了三个同类项目的成本明细逐项说明 |
| 你总是打断别人 | 今天会上小李发言时，你在他说完前开始讲自己的方案，一共两次 |

## 如何运用SBI模型进行反馈

运用SBI模型，不仅仅是套用一个公式，更是一种尊重、开放的沟通姿态。

1.  **第一步：准备反馈（S-B-I）**

    在进行反馈对话前，先自己在脑中或纸上，清晰地梳理好你的SBI内容。确保你的描述是具体、客观、无评判的。反馈要**及时**，最好在事情发生后的一两天内进行，时间越久，细节越模糊。

2.  **第二步：开启对话**

    选择一个合适的时间和地点。改进型反馈尽量私下进行，正面反馈可以根据对方的性格选择公开或私下。在对话开始时，先清晰地表明你的积极意图，例如，“我想和你分享一些我的观察，希望能帮助我们未来合作得更顺畅。”

3.  **第三步：清晰地陈述SBI**

    严格按照“S-B-I”的顺序，清晰、冷静地陈述你的反馈。

    *   “**（S）**在周一下午我们和客户开会时，**（B）**当客户提出关于预算的尖锐问题时，你立刻详细地列举了三个我们过往的成功案例来佐证我们的价值。**（I）**这让我感到非常安心和有底气，并且我看到客户的表情也明显放松了下来，这极大地增强了客户对我们的信任。”（这是一个积极反馈的例子）

4.  **第四步：暂停，并倾听对方的视角**

    在你说完SBI之后，最重要的一步是**停顿**，并把话语权交给对方。用一个开放式的问题来邀请对方分享他的看法，例如，“对于我刚才说的，你是怎么看的？”或者“我想听听你当时的想法是怎样的？”

5.  **第五步：共同探讨，面向未来**

    在双方充分交换了视角之后，将对话的焦点转向未来。共同探讨，“为了保持好的方面/改进不足的方面，我们未来可以做些什么？”

### 进阶：SBII（加上“意图”）

CCL 后来在 SBI 的基础上提出了 **SBII（Situation-Behavior-Impact-Intent）**，在最后增加一步：**询问对方当时的意图**。

很多冲突来自“意图”和“影响”之间的落差：对方的初衷可能是好的，只是造成了不好的影响。例如，同事在会上讲了 15 分钟背景，本意是想让大家充分理解问题，影响却是挤占了其他议题的时间。先描述影响，再询问意图，既让对方知道了行为的后果，也给了对方解释的机会，对话会更容易走向解决问题。

## SBI 话术模板

**改进型反馈**

> “我想跟你聊一下（某件事），希望能帮我们以后配合得更好。
> 在（具体时间、场合），我注意到你（具体行为）。
> 这让我/团队（具体影响）。
> 我想了解一下，你当时是怎么考虑的？”
>
> （听完之后）“下次遇到类似情况，你觉得我们可以怎么做？”

**正面反馈**

> “在（具体时间、场合），你（具体行为）。
> 这（带来了什么具体的好结果 / 对我和团队有什么帮助）。
> 谢谢你，希望以后也能继续这样做。”

**向上反馈**

> “我想跟您确认一件事，想把我这边的情况说清楚。
> 在（具体时间、场合），您（具体安排或决定）。
> 这对我手上的（具体工作）产生了（具体影响）。
> 您看这件事的优先级应该怎么排？或者我们可以怎么调整？”

## 应用案例

**案例一：给予一位会议发言冗长的同事反馈**

*   **不恰当的反馈**：“你开会太啰嗦了，每次都抓不住重点。”（评判性，模糊）
*   **SBI反馈**：
    *   **S**：“在今天上午的团队周会上，当我们讨论第三个议题‘下季度营销计划’时，”
    *   **B**：“我注意到，你在介绍你的方案时，详细地讲解了过去五年所有类似活动的背景资料，大约花了15分钟。”
    *   **I**：“这让我感到有些焦虑，因为我担心我们没有足够的时间来讨论其他两位同事的方案。同时，我也有点难以抓住你方案的核心要点是什么。”
    *   **询问意图**：“我想了解一下，你当时是希望确保我们都充分理解背景吗？”

**案例二：表扬一位主动帮助他人的新员工**

*   **不恰当的反馈**：“小王，你真棒，继续加油！”（模糊，缺乏指导意义）
*   **SBI反馈**：
    *   **S**：“小王，我注意到昨天下午，当客户支持团队都在忙着接电话时，”
    *   **B**：“你主动走过去，帮助他们一起处理了积压的5个在线工单。”
    *   **I**：“你的这个举动，不仅极大地缓解了客服团队的压力，也让整个团队的氛围变得更好了。非常感谢你！”

**案例三：向你的上级提出反馈（向上反馈）**

*   **场景**：你的上级经常在团队会议上，临时给你指派一些紧急任务。
*   **SBI反馈**：
    *   **S**：“在周三我们进行项目规划会时，”
    *   **B**：“您在会议的最后，给我布置了两个新的、需要在本周五前完成的紧急任务。”
    *   **I**：“这让我感到有些措手不及，因为这意味着我必须放下原计划中优先级最高的核心任务，才能完成它们。我担心这可能会影响我们整个项目的关键路径。”
    *   **开启对话**：“我想和您确认一下，这两个新任务的优先级，是否确实高于我目前正在进行的核心任务？或者我们能如何调整一下时间安排？”

**案例四：远程协作中的反馈**

*   **场景**：一位同事在协作文档里修改了你负责的部分，但没有留下任何说明。
*   **SBI反馈**：
    *   **S**：“周二下午我打开项目方案文档的时候，”
    *   **B**：“发现第二章的预算表被改动了，删掉了两行，但没有批注或修改记录说明。”
    *   **I**：“我花了半小时才确认改动的内容，也不确定这两项预算是否真的不需要了，没法回复财务的问询。”
    *   **询问意图**：“你当时是发现了什么问题吗？以后改动这类数据时，能不能留个批注，方便我们对一下？”

## 常见误区

1.  **把评判伪装成行为**。“你昨天在会上态度很消极”听起来有情境，但“态度消极”仍然是评判。行为部分只写看得到、听得到的内容。
2.  **影响说成了对方的人格**。“这说明你不够负责”不是影响，是新的评判。影响要落在具体后果上：时间、质量、客户、团队协作。
3.  **一次塞进太多问题**。一次反馈只谈一件事。把积攒了几个月的问题一次性倒出来，对方只会觉得被围攻。
4.  **只在出问题时才用**。如果 SBI 只出现在批评时，对方一听到“在某某时候”就会紧张。日常多用 SBI 做具体的正面反馈，改进型反馈才更容易被接受。
5.  **说完就走，不听对方怎么说**。SBI 的最后一步是倾听。跳过它，反馈就变成了单方面的指令。
6.  **拖太久才说**。“上个月某次会议上你……”这样的反馈，对方很难回忆细节，也会觉得你一直在“记账”。

## SBI、汉堡包反馈法和非暴力沟通的区别

| | SBI 反馈模型 | 汉堡包反馈法（三明治法） | 非暴力沟通（NVC） |
| --- | --- | --- | --- |
| 结构 | 情境 → 行为 → 影响（→ 意图） | 肯定 → 批评 → 鼓励 | 观察 → 感受 → 需要 → 请求 |
| 适用场景 | 工作中的正面和改进型反馈 | 需要缓和批评语气的场合 | 冲突、关系修复、情绪较强的沟通 |
| 优点 | 简单、客观，聚焦具体行为 | 容易被接受 | 深入情感与需要，关系导向 |
| 主要风险 | 用得生硬时像在念公式 | 听者容易只记住表扬或只记住批评，久了会对表扬产生戒备 | 学习门槛较高，用于日常工作反馈稍显繁复 |

## SBI模型的优势与挑战

**核心优势**

*   **具体、客观、有据可依**：将反馈建立在可观察到的事实上，避免了空泛的赞扬和无端的指责。
*   **降低防卫心理**：通过聚焦于“行为”及其“影响”，而非评判“个人”，极大地降低了对方的抵触情绪，让对话更容易进行。
*   **清晰地指明方向**：“影响”部分清晰地告诉了对方，为什么他的行为需要被保持或改变，使其更容易理解和采取行动。
*   **简单易学**：模型结构简单，易于记忆和在日常工作中刻意练习。

**潜在挑战**

*   **需要刻意练习**：要熟练地、自然地运用SBI，尤其是在面对冲突或需要给予负面反馈时，需要大量的刻意练习，以克服我们习惯性的、带有评判的沟通模式。
*   **对“行为”的观察要求高**：需要我们平时就做一个有心的观察者，能够捕捉并准确地描述具体的行为细节。

## 常见问题

??? question "SBI 反馈模型是谁提出的？"

    由美国的创新领导力中心（Center for Creative Leadership, CCL）开发，是其领导力培训中的核心沟通工具。CCL 后来又推出了加入“意图（Intent）”的扩展版本 SBII。

??? question "SBI 可以用来表扬吗？"

    可以，而且很推荐。具体的正面反馈让对方清楚地知道哪些行为是好的、为什么好，从而更可能重复这些行为。“你真棒”带来的只是一时的好心情。

??? question "SBI 和非暴力沟通哪个更好？"

    适用场景不同。SBI 结构更简单，适合工作中日常、高频的反馈；非暴力沟通更关注双方的感受和需要，适合情绪较强的冲突和关系修复。两者理念相通，SBI 的“情境+行为”就相当于 NVC 的“观察”。

??? question "对方不接受反馈怎么办？"

    先确认你的“行为”描述里没有评判，再认真听对方的解释，他可能掌握你不知道的信息。如果分歧仍在，可以把焦点转向未来：“不管当时的原因是什么，下次遇到类似情况，我们怎么做比较好？”

??? question "给上级反馈也可以用 SBI 吗？"

    可以。向上反馈时，影响部分尽量落在工作结果上（进度、质量、优先级），并以确认和商量的语气收尾，例如“您看这个优先级怎么排比较合适？”。

## 延伸与关联

*   **非暴力沟通（Nonviolent Communication, NVC）**：SBI模型与非暴力沟通的理念高度契合。NVC的四要素是“观察、感受、需要、请求”，SBI中的“情境-行为”对应“观察”，“影响”则深刻地关联着我们的“感受”和“需要”。
*   **[ORID 聚焦式对话](../meeting_effectiveness/ORID-Focused-Conversation-Tutorial-zh.md)**：同样从客观事实出发，按“事实—感受—意义—决定”展开，适合用于团队复盘中的集体反馈。
*   **[金字塔原理](../logical_thinking/Pyramid-Principle-Tutorial-zh.md)**：书面反馈或较长的反馈，可以用结论先行的方式组织，让对方先抓住重点。
*   **[RACI 矩阵](../team_collaboration/RACI-Matrix-Tutorial-zh.md)**：很多反馈的根源是职责不清。如果同类问题反复出现，可以用 RACI 把分工讲清楚。
*   **[六顶思考帽](../ideation/Six-Thinking-Hats-Tutorial-zh.md)**：团队讨论中，“黑帽”阶段提出的问题，可以用 SBI 的方式描述得更具体、更不伤人。
